# StreakFocus-YOLO

This repository accompanies the paper "StreakFocus-YOLO" (Chenyang Zeng) on wood surface defect detection with the Kodytek wood defect dataset.

## Data splits

The `splits/` folder contains the image lists used in the paper:

- `train.txt`: 12,792 training images
- `val.txt`: 1,827 validation images
- `test.txt`: 3,656 test images
- `splits.json`: the same split in JSON form
- `class_stats.json`: per-class instance counts for each split
